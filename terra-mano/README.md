# Terra Mano — Punto Café Lite mockup

Private prospect mockup for Eureka Websites. This mobile-first static demo shows
an additional direct-order and pickup channel for Terra Mano Café. It does not
replace or modify Terra Mano's existing ecommerce site or marketplace channels.

## Scope

- Functional category filters, cart, pickup time, and payment-choice simulation.
- One verified pickup location only: Plaza Master, Querétaro.
- Publicly listed menu names and reference prices.
- Direct link to Terra Mano's existing coffee-bean and subscription store.
- No orders, payments, forms, messages, or data collection.

## Public references

- `https://terra-mano.com/`
- `https://www.instagram.com/terramanocafe/`
- Terra Mano's public Uber Eats storefront for the Querétaro location.

All Terra Mano imagery and marks are used only for this private sales mockup.
